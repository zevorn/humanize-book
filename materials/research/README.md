# 一手资料核查

研究文件统一使用 `NN_主题_一手资料核查.md` 命名：

- `00_`：全书 Agent 发展史的公共背景与总览；
- `01_` 至 `04_`：对应四个章节；
- `99_`：资料整理审计、待核项目和归档说明。

每份核查稿都尽量把内容分成三层：厂商/仓库可直接支持的事实、群内同期判断、仍需验证的编辑假说。正文引用时优先使用第一层，第二层保留语气和时间边界，第三层不得写成定论。
