## DeepSeek-V4-Flash-0731

2026-07-31，DeepSeek 发布
[DeepSeek-V4-Flash-0731 Model Card](https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash-0731/blob/main/README.md)。
官方将它称为取代 Preview 的正式版，并公布了下列 Agent 评测：

| Benchmark | V4 Flash 0731 | GLM-5.2 | Opus 4.8 |
| --- | ---: | ---: | ---: |
| Terminal-Bench 2.1 | 82.7 | 81.0 | 85.0 |
| DeepSWE | 54.4 | 46.2 | 58.0 |
| Agents' Last Exam | 25.2 | 23.8 | 25.7 |
| DSBench-FullStack | 68.7 | 61.8 | 71.6 |

以上数字来自厂商 Model Card；其中 DSBench-FullStack 与 DSBench-Hard
是内部测试集。公开项目中，V4 Flash 0731 与当时的强闭源模型已经进入
相近区间，同时仍有明确差距。正文采用“广泛接近、可以正面竞争”，
不扩写为全面领先。

Model Card 的评测注释尤其关键：Code Agent 项目使用 **DeepSeek
Harness minimal mode (to be released)**，并开启 `max` Reasoning
Effort。该 Harness 截至 2026-08-05 仍没有公开链接。群里随后出现内部
试用与“雷霆震撼”的转述，这类信息无法独立核验，只能记录为社区传闻。

## V4 Pro 的时间勘误

[DeepSeek V4 Preview 公告](https://api-docs.deepseek.com/news/news260424/)
显示，V4-Pro Preview 与 V4-Flash Preview 已于 2026-04-24 同时开放
API 和权重。7 月 31 日获得独立正式版的是 V4 Flash；其 Model Card
仍把比较对象写成 `DeepSeek-V4-Pro (Preview)`。

因此，第四章可以把以下事项列为待观察：

1. V4 Pro 是否出现与 `0731` 对应的后续正式版本；
2. DeepSeek Harness 何时公开，以及 Minimal Mode 实际包含什么；
3. 同一模型换用官方 Harness、Bare Pi 和其他 Coding CLI 后，可靠性、
   成本与强约束遵循会怎样变化。

不能把“等待 Pro 正式版”简写成“等待 DeepSeek V4 Pro 发布”，否则会
抹掉 4 月 Preview 已经公开的历史事实。
