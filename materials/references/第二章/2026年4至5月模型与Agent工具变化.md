## 这一阶段值得保留的四个特征

1. **长程执行成为模型能力的一部分。** 厂商介绍逐渐从单轮 Coding 分数转向规划、工具调用、持续运行、自校验和端到端交付。
2. **成本、速度和智力开始分档。** DeepSeek 的 Pro/Flash、Claude/GPT 的 Effort 与 Fast 选项，让“便宜 Builder + 强 Reviewer”这类异构 Flow 具备现实基础。
3. **开放权重与协议兼容降低替换成本。** 国产模型一边开放权重，一边兼容 OpenAI/Anthropic API；Coding CLI 也开始提供 Multi-provider。Flow 继续硬绑定单一模型，维护代价会越来越高。
4. **Harness 能力向产品内部移动。** `/goal`、Dynamic Workflows、内置 Subagents 与插件系统逐步覆盖原先需要外部脚手架实现的目标保持、循环、并行和验证。

这些变化共同解释了 Humanize 2 的问题意识：模型选择需要从 Flow 中抽离，Flow 自身也需要成为可描述、可检查、可替换后端的工程对象。
