# Humanize Book 编辑材料

这里存放《Humanize Book》正文之外的时间线、史料核查、参考资料卡和检索工具。
根目录 [README](../README.md) 是小册子正文入口。

## 目录结构

| 目录 | 用途 | 阅读定位 |
| --- | --- | --- |
| [`timeline/`](timeline/) | 按日期整理的关键节点与阶段导览 | 首选入口 |
| [`research/`](research/) | 对群聊、仓库、公告和技术文档做的证据核查 | 写作与勘误依据 |
| [`references/`](references/) | 按章节拆分的短资料卡 | 快速复查 |
| [`indexes/`](indexes/) | 原文行号、链接和主题索引 | 精确回溯 |
| [`figures/`](figures/) | 正文使用的图表源文件 | 出版素材 |
| [`sources/`](sources/) | 录音/OCR 语料与历史草稿 | 仅供追溯，不是正文入口 |

## 推荐阅读顺序

1. 先看[关键节点导览](timeline/01_Agent发展史_关键节点导览.md)，确定时间段和讨论主题。
2. 再看对应章节的[一手资料核查](research/)，区分同期事实、群内判断和编辑假说。
3. 需要快速查资料时，打开对应章节的[参考资料卡](references/)。
4. 需要回到聊天上下文时，使用[主题与原文索引](indexes/01_Agent篇_主题与原文索引.md)或[群聊链接索引](indexes/02_Agent发展史_群聊引用链接索引.md)。
5. 最后再打开[录音/OCR 归档](sources/01_录音与OCR/)，核对连续语境和原始行号。

## 录音与 OCR 说明

当前仓库没有保存录音或聊天截图二进制。录音转写、Typeless 导出和 OCR 内容的可追溯入口见[`sources/01_录音与OCR/`](sources/01_录音与OCR/)。外部原始 OCR 文件仍位于维护者本机的 Downloads 目录，仓库只保存脱敏后的高召回文本和必要的行号索引，避免把敏感信息再次提交到版本库。

高召回文本保留了大量上下文，适合查证，不适合直接阅读或发布。琐碎对话、OCR 残片和未核验链接不会进入正文；正文写作以时间线、研究核查和参考资料卡为准。

## 历史草稿说明

早期主题总结已移到[`sources/02_历史草稿/`](sources/02_历史草稿/)。它们用于追踪写作思路的变化，不代表当前正文，也不替代一手资料核查。
